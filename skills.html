Skill 1: Algorithm Design with Nested IF Statements

The problem. At BAC a student can score any mark between 0% and 100% inclusive. The mark determines the grade as follows:

Mark rangeResult
0 - 39Fail
40 - 59Pass
60 - 69Merit
Above 69Distinction

Required. Use nested IF statements to write logic that determines the result a student achieves based on the mark they score.

My solution (pseudocode)

START
IF mark >= 0 AND mark <= 100 THEN
    IF mark <= 39 THEN
        PRINT "Fail"
    ELSE
        IF mark <= 59 THEN
            PRINT "Pass"
        ELSE
            IF mark <= 69 THEN
                PRINT "Merit"
            ELSE
                PRINT "Distinction"
            ENDIF
        ENDIF
    ENDIF
ELSE
    PRINT "Invalid mark"
ENDIF
STOP

How it works

The outer IF first validates the mark, so anything below 0 or above 100 prints "Invalid mark". Inside it, the conditions are tested from the lowest range upwards. Each ELSE branch only runs when the previous condition was false, so the upper limit of each range does not need to be repeated.

Skill 2: Troubleshooting a Computer

Troubleshooting is a technique used to identify and analyse a problem and come up with a solution for that particular problem.

Scenario. As a computer systems engineer, a home user calls you because their computer is failing to connect to the network at home. What measures will you take to solve this connectivity issue?

My solution

  1. Identify the problem. Ask the user about the connectivity issue.
  2. Establish a theory. Identify the possible causes of the problem.
  3. Test the theory. Check whether the suspected cause is correct.
  4. Plan and implement a solution. Apply the appropriate fix.
  5. Verify functionality. Confirm that internet access works.
  6. Document findings. Record the problem, its cause and the solution.
